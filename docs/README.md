# VEV documentation

Public, engineer-to-engineer documentation for VEV products and platform
concepts. For now these pages are read directly on GitHub — there is no separate
documentation website yet (see [Where these docs live](#where-these-docs-live)).

## Sections

- [Atlas](atlas/README.md) — documentation for Atlas Community, including the
  contextual help targets the product deep-links into.

## Where these docs live

The product UI links straight into this repository on GitHub rather than a
hosted `docs.*` site. This keeps product links stable immediately, needs no
extra website to build or host, and keeps everything under normal public PR
review and version history. A dedicated documentation site can be introduced
later without changing the authored markdown; the anchor registry below is the
contract the product relies on in the meantime.

- Anchor registry (source of truth): [`atlas/anchors.md`](atlas/anchors.md)
